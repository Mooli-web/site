# نسخهٔ PHP سایت کلینیک — مخصوص هاست اشتراکی

این پوشه بازنویسی کامل سایت جنگو به **PHP خالص (بدون فریم‌ورک و بدون Composer)** است تا روی ارزان‌ترین هاست‌های اشتراکی (پارس‌پک، …) با cPanel/DirectAdmin اجرا شود.

- همان طراحی (Tailwind + HTMX + Alpine + فونت وزیرمتن)، همان مسیرها، همان فلوی رزرو ۴ مرحله‌ای و پرداخت زرین‌پال
- پایگاه داده **SQLite** (یک فایل؛ نیاز به MySQL ندارد — روی هاست رایگان ۱۰۰ مگابایتی هم جا می‌شود)
- پنل «تنظیمات و محتوا» جایگزین ادمین جنگو (خدمات، ساعات کاری، تعطیلات، سوالات متداول، گالری، پیام‌ها، مشتریان، کاربران، بکاپ)
- نیازمندی: **PHP ≥ 8.1** با افزونه‌های `pdo_sqlite`, `mbstring`, `curl` (یا `allow_url_fopen`) — همگی روی هاست‌های معمول فعال‌اند.

## ساختار

```
php-app/
├── public/            ← ریشهٔ وب (public_html)
│   ├── index.php      فرانت‌کنترلر
│   ├── .htaccess      بازنویسی مسیرها
│   ├── static/        css / js / فونت / تصاویر
│   └── media/         تصاویر آپلودی گالری
├── app/
│   ├── bootstrap.php  مسیرها و اجرای برنامه
│   ├── lib/           Jalali, Core (Router/DB/Session/CSRF/Auth), Schema, Models, helpers
│   ├── controllers/   Website, Payment, Dashboard, Admin
│   └── views/         قالب‌های PHP (پورت مستقیم قالب‌های جنگو)
├── storage/           db/ (SQLite)، sessions/، logs/
├── .env.example
└── README.md
```

## نصب روی هاست پارس‌پک (cPanel)

1. **PHP:** در cPanel → *Select PHP Version* نسخه‌ی 8.1 یا بالاتر را انتخاب و مطمئن شوید `pdo_sqlite`, `sqlite3`, `mbstring`, `curl` تیک خورده‌اند.
2. **آپلود:** محتوای `php-app/` را (به‌جز `.env.example`) در **پوشه‌ای بیرون از public_html** آپلود کنید، مثلاً `~/clinic/`. سپس:
   - یا `public_html` را به `~/clinic/public` پوینت کنید (cPanel → Domains → Document Root)،
   - یا اگر امکانش نیست، محتوای `public/` را داخل `public_html` بریزید و در `public_html/index.php` خط `define('BASE_PATH', dirname(__DIR__));` را به مسیر پوشه‌ی `clinic` تغییر دهید:
     `define('BASE_PATH', '/home/USERNAME/clinic');`
3. **.env:** فایل `.env.example` را به `.env` کپی کنید (کنار `app/`) و پر کنید:
   ```
   APP_URL=https://yourdomain.ir
   DEBUG=false
   ZARINPAL_MERCHANT_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
   ZARINPAL_SANDBOX=false
   ```
4. **دسترسی نوشتن:** پوشه‌های `storage/` (و زیرپوشه‌ها) و `public/media/` باید قابل نوشتن باشند (`755` معمولاً کافی است چون PHP با کاربر خودتان اجرا می‌شود؛ در غیر این‌صورت `775`).
5. **راه‌اندازی اولیه:** دامنه را باز کنید → صفحهٔ «راه‌اندازی اولیه» نمایش داده می‌شود → نام کلینیک، نام کاربری و رمز مدیر را وارد کنید. گزینهٔ «داده‌های نمونه» چند خدمت و ساعات کاری پیش‌فرض می‌سازد تا سریع شروع کنید (بعداً از پنل قابل ویرایش‌اند).
6. **SSL:** در cPanel → SSL/TLS Status → Let's Encrypt رایگان را فعال کنید (یا گواهی خودتان را نصب کنید).

> اگر بعد از نصب صفحهٔ ۴۰۴ هاست را دیدید، یعنی `mod_rewrite` یا `.htaccess` اعمال نشده؛ از پشتیبانی بخواهید `AllowOverride All` فعال باشد.

### DirectAdmin
مشابه بالا؛ ریشهٔ وب `~/domains/DOMAIN/public_html` است. اگر نمی‌توانید ریشه را تغییر دهید، از روش دوم مرحلهٔ ۲ استفاده کنید.

## پنل مدیریت

| مسیر | توضیح |
|---|---|
| `/dashboard/login/` | ورود منشی/مدیر |
| `/dashboard/` | نوبت‌ها (فیلتر، تغییر وضعیت، حذف — با HTMX بدون رفرش) |
| `/dashboard/consultations/` | درخواست‌های مشاوره |
| `/admin/` | تنظیمات و محتوا (جایگزین ادمین جنگو) |
| `/admin/backup/` | دانلود بکاپ کامل SQLite |

## انتقال داده‌های فعلی از جنگو

اگر روی نسخهٔ جنگو دیتای واقعی دارید:
```bash
# روی سرور/سیستم فعلی جنگو
python manage.py export_for_php --out export.json
```
سپس در پنل PHP → `/admin/import/` فایل را آپلود کنید (تیک «پاک کردن داده‌های فعلی» را بزنید تا داده‌های نمونهٔ راه‌اندازی حذف شوند). تصاویر گالری را دستی از `media/before_after/` به `php-app/public/media/before_after/` کپی کنید. کاربران پنل باید با رمز جدید دوباره ساخته شوند.

## نکات نگهداری

- **بکاپ:** پارس‌پک بکاپ روزانه می‌گیرد، اما هر چند وقت یک‌بار از `/admin/backup/` هم فایل را دانلود کنید. برای بازگردانی کافی است فایل را جای `storage/db/clinic.sqlite` بگذارید.
- **لاگ خطا:** `storage/logs/php-error.log`
- **زرین‌پال:** آدرس کال‌بک به‌صورت خودکار `APP_URL + /payment/<کد>/callback/` ساخته می‌شود؛ در پنل زرین‌پال نیاز به تنظیم خاصی نیست.
- **محدودیت نرخ:** فرم‌های تماس/مشاوره/رزرو ۵ بار در ۱۰ دقیقه به‌ازای هر IP، ورود ۱۰ بار.
- **تغییر CSS:** کلاس‌های Tailwind از روی `php-app/app/views/**` هم استخراج می‌شوند؛ بعد از تغییر قالب‌ها در ریشهٔ ریپو `bash build_css.sh` را اجرا و `static/css/tailwind.css` را به `php-app/public/static/css/` کپی کنید.

## اجرای محلی

با PHP معمولی:
```bash
cd php-app && cp .env.example .env
php -S 0.0.0.0:8000 -t public public/index.php
```
برای تست پرداخت بدون اینترنت می‌توانید موقتاً `ZARINPAL_FAKE=true` را در `.env` بگذارید (درگاه شبیه‌سازی می‌شود). **روی سرور واقعی هرگز فعال نکنید.**

## تفاوت‌ها با نسخهٔ جنگو

- به‌جای MySQL/Postgres از SQLite استفاده می‌شود (برای ترافیک یک کلینیک بیش از حد کافی است؛ حالت WAL فعال است).
- ادمین جنگو با پنل سبک `/admin/` جایگزین شده؛ همهٔ مدل‌ها (دسته‌ها، خدمات، ساعات کاری، تعطیلات، سوالات، گالری، پیام‌ها، مشتریان، کاربران) قابل مدیریت‌اند.
- محدودیت نرخ در جدول SQLite ذخیره می‌شود (نیازی به Redis/Memcached نیست).
- فیلد «کارمند/پرسنل» که در نسخهٔ جنگو استفاده نمی‌شد حذف شده است.
